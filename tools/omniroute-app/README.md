# OmniRoute & Claude Code Desktop Manager (for JARVIS)

A standalone web control center and launcher application for managing OmniRoute and running Claude Code with multi-provider AI profiles (Free auto-routers, Gemini, Antigravity, Nvidia NIM, Kiro, and custom combos).

## Quick Start

Run from the project root:
* Double click `Launch-OmniRoute-Web.bat` or run:
```cmd
cd tools\omniroute-app
launch-app.bat
```

* Opens the manager in your browser at `http://localhost:42100`.
* Live OmniRoute status indicator (Online / Offline).
* Select working project directory (`A:\Projects\AI-Companion`, `A:\Projects`, etc.).
* Search and filter through 330+ profiles.
* 1-Click "Launch in Terminal" button for any profile.
